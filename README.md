# BHVR Engine
BHVR (Short for BEHAVIOR) is a modular-based game engine inspired by the RAGE Game Engine by Rockstar. BHVR is unlike other game engines, freely handing core definitions to the programmer instead of designing the systems for them.
## How does it work?
BHVR's core runtime is restricted, as it provides necessary items to work. Lua is BHVR's scripting language of choice. The runtime embeds its own Lua Virtual Machine (LVM) into itself.
## Do I have to design my own core modules every time I want to design a game?
No actually! BHVR lets you choose from presets if you do not want to design your own modules.
